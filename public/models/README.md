# Founders’ Affair 3D model sources

These public GLB models load at runtime from GitHub and are used as decorative scene geometry in the scroll-driven tunnel.

Source collection: [ToxSam/cc0-models-Polygonal-Mind](https://github.com/ToxSam/cc0-models-Polygonal-Mind)

The collection is listed as CC0 by [ToxSam/open-source-3D-assets](https://github.com/ToxSam/open-source-3D-assets), whose registry says Polygonal Mind collections are CC0 1.0. CC0 does not require attribution, but source links are retained for provenance.

- Aero_Station_Ring_Art.glb — https://github.com/ToxSam/cc0-models-Polygonal-Mind/blob/main/projects/aero-system/Aero_Station_Ring_Art.glb
- Aero_Door_01.glb — https://github.com/ToxSam/cc0-models-Polygonal-Mind/blob/main/projects/aero-system/Aero_Door_01.glb
- Aero_Lampost_01.glb — https://github.com/ToxSam/cc0-models-Polygonal-Mind/blob/main/projects/aero-system/Aero_Lampost_01.glb

Runtime note: the files load from raw.githubusercontent.com through Three.js GLTFLoader. The original procedural rendering remains available if an external model or the module CDN fails.
